# Subagents

Папка содержит постоянные профили субагентов для проекта CrossfitArmyJym.

Использование:

1. Выбери профиль по `.codex/subagents/subagents.yaml`.
2. Передай субагенту содержимое соответствующего `.md` как роль/инструкцию.
3. Ограничь задачу конкретным вопросом или областью файлов.
4. После ответа субагента проверь результат основным агентом и зафиксируй изменения в `context/progress.md`, если работа меняет состояние проекта.

Субагенты не заменяют основного исполнителя. Они помогают проектировать, расследовать, проверять и снижать риск перед изменениями.
